# What is "SeisDown" ?

SeisDown is a lightweight and user-friendly software designed to facilitate the download of seismic data.

# How to use the software ?
- Start by installing Python3. Just click here to download : https://www.python.org/downloads/
- After that, you will need a seismic catalog. For example, you can use one in the "catalog_for_example" folder.
- Once you have a catalog, download the "installation" and "SeisDown" codes from GitHub. Place them in a folder of your choice.
- Run the installation script to install the necessary Python modules for using SeisDown.
- Run SeisDown, wait for a few seconds and follow the instructions inside the software.
